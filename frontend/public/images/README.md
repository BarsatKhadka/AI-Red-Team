# Member Profile Images

Place the following images in this directory:

1. **alice.jpg** - First image (young man with dark hair and beard, low-angle selfie with blue sky)
2. **bob.jpg** - Second image (woman holding a child, outdoor moment with trees)

The images should be:
- JPG format (or PNG, but update the file extensions in `frontend/src/utils/memberImages.js` if using PNG)
- Recommended size: 200x200 pixels or larger (will be displayed as circular avatars)
- Square aspect ratio works best

After adding the images, they will automatically appear in:
- Team Members Panel
- Member Bio Summary
- Dashboard message displays
